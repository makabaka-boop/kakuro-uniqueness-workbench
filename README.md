# 数和（Kakuro）离线编辑器

用 Svelte + TypeScript 实现的纯前端数和谜题编辑器：编辑棋盘与线索、实时校验、
查看每个白格在约束传播阶段剩余的候选数字，并对整盘求解分类（无解 / 唯一解 / 多解）。

## 规则与约束

- 棋盘至多 10×10，白格不超过 28 个；
- 每条横、竖连续白格长度为 2～6（编辑器据此保证每个白格恰属一条横线与一条竖线）；
- 线索为 3～45 的整数，且必须能被该长度的线用互不相同的 1～9 数字凑出；
- 白格填 1～9，同一条线内数字不得重复。

## 求解器（`src/lib/solver.ts`）

1. **候选组合约束传播**：每条线的可行填法枚举为“len 个不同 1～9 数字、和为线索”的全部
   有序元组；白格候选 = 横线该位置可用数字 ∩ 竖线该位置可用数字，迭代过滤到不动点。
2. **回溯搜索**：按行优先顺序选取第一个未定白格、数字升序尝试，传播剪枝，
   **找到第二个解即停**。因此：
   - 解按行优先字典序枚举，多解时展示的两份完整填法就是字典序最小的两份；
   - 只有确认不存在第二个解时才报“唯一解”，绝不会把多解误称为唯一解。

任何格子或线索的修改都会立即使上一次求解结论失效；候选数字视图随编辑实时重算。

## 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm run test     # Vitest：含小盘面全枚举对照
npm run check    # svelte-check 类型检查
npm run build    # 产出 dist/
```

## Docker / Compose

```bash
docker compose up --build
# 打开 http://localhost:8080
```

Compose 服务 `puzzle` 通过多阶段构建（Node 构建 → nginx 托管）提供 puzzle 页面，
运行时无需任何外部服务，完全离线。

## 测试策略（`src/test/solver.test.ts`）

- 组合生成的计数与边界（最小/最大和、不可行和）；
- 手工小盘面：唯一解（内置示例）、多解（2×2 全 5，断言两个见证的具体内容）、
  无解（竖线和矛盾）、传播候选内容；
- 非法输入：线索越界/非整数/该长度凑不出、孤立白格、线长超 6、贴边线缺线索格、
  白格超 28、缺线索时禁止求解；
- **随机小盘面全枚举对照**：150 个随机盘面 × 3 种线索（可解、扰动、随机），
  用独立的暴力枚举（`src/test/brute.ts`，不使用组合传播）核对分类与两个见证，
  并验证字典序——保证不会把可能的答案误称为唯一答案。
